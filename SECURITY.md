# Security policy

This repository contains audit tooling, public metadata, and derived source-scoped patches.

## Do not disclose sensitive material

Do not open an issue or pull request containing credentials, private exports, personal data, access tokens, or unredacted local paths. Do not commit original translation exports or SQL databases.

## Reporting a security issue

For a vulnerability in the audit tooling, use GitHub's private vulnerability reporting for this repository when available. If private reporting is unavailable, open a minimal issue without sensitive details and request a private contact route.
