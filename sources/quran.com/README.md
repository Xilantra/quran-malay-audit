# Quran.com source track

This folder contains the audit record for Quran.com Content API v4 resource 39, Abdullah Muhammad Basmeih.

| File | Purpose |
| --- | --- |
| `source.json` | Provider, resource identity, retrieval state, and licensing boundary |
| `corrections.json` | 197 confirmed, source-scoped textual corrections |
| `findings.json` | Finding ledger for this source track |

The correction manifest is guarded by `source_key: qurancom-ms-39`, `resource_id: 39`, exact verse keys, and exact `find` text. It must not be applied to another provider or resource.

The repository stores the correction catalog and audit metadata, not a full translation dump. Review the [Quran Foundation Content API documentation](https://api-docs.quran.com/docs/content_apis_versioned/4.0.0/content-apis/) and current provider terms before redistributing source text.
